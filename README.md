# 문자열 덧셈 계산기

## 기능 목록

### 1. 입력값 처리

- 입력값이 'null' 또는 빈 문자열("")일 경우 0을 반환한다.

### 2. 구분자 처리

- 기본 구분자 쉼표(,) 또는 콜론(:)을 사용해 문자열을 분리한다.
- 문자열 앞부분이 '//[구분자]\n' 형식인 경우, 해당 구분자를 이용해서 문자열을 분리한다.
- 커스텀 구분자가 숫자일 경우 예외 처리한다.
- 커스텀 구분자 사용 시 기본 구분자를 혼용하면 예외 처리한다.
- 숫자 하나만 입력되면 그대로 반환한다.

### 3. 숫자 추출 및 검증

- 문자열 배열을 정수 배열로 변환한다.
- 정수가 아닌 값이 입력된 경우 예외 처리한다.
- 0 이나 음수가 입력된 경우 예외 처리한다.
- 빈 값이 입력된 경우 예외 처리한다.

### 4. 숫자 계산

- 추출한 숫자들을 합산하여 결과를 반환한다.

### 5. 예외 처리

- 예외 발생 시 IllegalArgumentException을 발생시키고 프로그램을 종료한다.
